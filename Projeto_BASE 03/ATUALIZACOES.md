## 🎯 Como Usar

### Adicionar Produto ao Carrinho
1. Clique no botão "🛒 Adicionar" em qualquer pizza
2. Veja a notificação de confirmação
3. O badge do carrinho atualiza com a quantidade

### Gerenciar Carrinho
1. Clique no ícone 🛒 no header
2. Aumente ou diminua a quantidade
3. Clique em "Remover" para tirar um item
4. Veja o total atualizar em tempo real

### Fazer Pedido
1. Com os itens no carrinho, clique em "Fazer Pedido no WhatsApp"
2. Será aberta uma conversa no WhatsApp com o resumo do pedido
3. Envie a mensagem para confirmar

### Buscar Pizza
1. No menu, use a caixa de busca
2. Digite o nome da pizza que procura
3. Os resultados aparecem em tempo real
