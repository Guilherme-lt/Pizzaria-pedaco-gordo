# Big Fat Slice

Site fictício de uma pizzaria desenvolvido para estudos de HTML e CSS.

## Sobre o projeto

O Big Fat Slice é um projeto criado com o objetivo de praticar estruturação de páginas web, estilização e organização de layout utilizando HTML5 e CSS3.

O site foi desenvolvido por André, Guilherme e Alissa, com foco em uma identidade visual inspirada em pizzarias modernas, utilizando banners promocionais, cards de produtos e navegação entre páginas.

## Páginas

### Home
- Banner principal
- Área de destaque
- Localização
- Rodapé informativo

### Menu
- Pizzas salgadas
- Pizzas doces
- Navegação por âncoras
- Cards de produtos

## Tecnologias utilizadas

- HTML5
- CSS3
- Google Fonts

## Recursos utilizados

- Flexbox
- Gradientes
- Animações CSS
- Efeitos hover
- Scroll suave
- Responsividade

## Objetivo

Projeto desenvolvido para aprendizado e prática de desenvolvimento front-end.
